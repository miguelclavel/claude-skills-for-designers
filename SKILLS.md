# Every skill, by job

All 28 of my Claude Code skills in one place, grouped by the job you're doing. Find the job, pick the skill, and either install the plugin it lives in or copy just that folder.

Two plugins, one marketplace:

```
/plugin marketplace add miguelclavel/claude-skills-for-designers
/plugin install claude-skills-for-designers@miguelclavel
/plugin install ux-research-skills@miguelclavel
```

**Designers** = [claude-skills-for-designers](https://github.com/miguelclavel/claude-skills-for-designers) (10) · **Research** = [ux-research-skills](https://github.com/miguelclavel/ux-research-skills) (18)
